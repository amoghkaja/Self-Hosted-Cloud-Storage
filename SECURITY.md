# Security policy

Family Cloud stores people's private files, so security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Instead, use GitHub's private reporting: the repository's **Security** tab → **Report a vulnerability**.

Include what you found, how to reproduce it, and the impact you expect. You'll get an acknowledgement within a few days, and credit in the fix's release notes if you'd like.

## Supported versions

Security fixes are made on the latest release. Keep your installation updated (see [docs/self-hosting.md](docs/self-hosting.md#updating)).

## Design and past reviews

The threat model, the security controls and the results of the most recent review are documented in [docs/security.md](docs/security.md).
